# Contrastive Fine-Tuning

## Что такое Contrastive Fine-Tuning?

Контрастное обучение (Contrastive Learning) — это способ обучения представлений (эмбеддингов), при котором модель учится:

- Приближать похожие объекты (positive pairs)
- Отдалять разные объекты (negative pairs)

## Разновидности

### 1. Triplets: (anchor, positive, negative)

Пример:

```python
("Как дела?", "Привет, как ты?", "У меня сломался двигатель")
```

- Модель учится делать эмбеддинг anchor ближе к positive, чем к negative
- Используется `TripletLoss`

`Triplet Loss`
$$
L = \max \left( d(a, p) - d(a, n) + \text{margin},\ 0 \right)
$$
Где:
- $a$ — anchor (якорный пример)
- $p$ — positive (положительный, похожий пример)
- $n$ — negative (отрицательный, непохожий пример)
- $d(x, y)$ — функция расстояния (например, евклидово или косинусное расстояние)
- $\text{margin}$ — отступ (гиперпараметр, минимальная разница между положительной и отрицательной парами)

### 2. Pairs + Label: (text_a, text_b, label=1/0)

Пример:

```python
("Кто такой Эйнштейн?", "Альберт Эйнштейн — физик.", label=1)
("Кто такой Эйнштейн?", "Я люблю шоколад.", label=0)
```

- Обучение с `CosineSimilarityLoss` или `ContrastiveLoss`

`CosineSimilarityLoss`
$$
L = 1 - \cos(\theta) = 1 - \frac{ x_1 \cdot x_2 }{ |x_1| \cdot |x_2| }
$$
Где:
- $x_1, x_2$ — эмбеддинги двух объектов
- $\cos(\\theta)$ — косинусное сходство между векторами $x_1$ и $x_2$

`Contrastive Loss`
$$
L = (1 - y) \cdot \frac{1}{2} D^2 + y \cdot \frac{1}{2} \left[ \max(0, m - D) \right]^2
$$
Где:
- $y \in {0, 1\\}$ — метка (0 — разные, 1 — похожие)
- $D = | x_1 - x_2 |$ — расстояние между эмбеддингами (обычно евклидово)
- $m$ — margin (отступ, минимальное расстояние между разными классами)

### 3. Hard Negatives

Это подтип триплетов или пар, где негативные примеры "похожи", но неправильны. Модель вынуждена научиться лучше различать нюансы.

Пример:

```python
("барселона достопримечательности", 
 "что посмотреть в барселоне",             # ← positive
 "барселона футбольный клуб история")       # ← hard negative
 ```

- Отличие от обычных негативов: они семантически близки, но не релевантны.
- Можно использовать в `TripletLoss` или `MultipleNegativesRankingLoss`

`MultipleNegativesRankingLoss`
$$
L = -\frac{1}{N} \sum_{i=1}^{N} \log \frac{ \exp(\text{sim}(a_i, p_i)) }{ \sum_{j=1}^{N} \exp(\text{sim}(a_i, p_j)) }
$$
Где:
- $N$ — размер батча
- $a_i$ — anchor (якорный пример) в батче
- $p_i$ — positive (положительный пример) для $a_i$ (обычно парный пример)
- $\text{sim}(a, b)$ — функция сходства (обычно косинусное сходство)
- В знаменателе — все positive из батча считаются негативами для других anchor

# Модуль обучения модели (train_model.py)

### 1. Назначение

Модуль предназначен для обучения модели определения семантической схожести диалогов на размеченных данных.

------------

### 2. Входные данные

Файл Excel (например, dialogs.xlsx) со следующими колонками:
- dialog: текст диалога в формате:
  Клиент: [текст запроса]
  Менеджер: [текст ответа]
  ...
- label: тема диалога (например, "Кредит", "Депозит", "Эквайринг")

----------------

### 3. Основные компоненты

1) Классы датасетов:
   - DialogDataset: базовый класс для работы с диалогами
   - InputExamplesDataset: класс для работы с парами диалогов

2) Функции подготовки данных:
   - load_dialogs_from_excel(): загрузка диалогов из Excel
   - prepare_training_data(): создание обучающих пар
   - split_train_val_data(): разделение на train/val выборки

3) Функции обучения:
   - train_model(): основная функция обучения
   - evaluate_model(): оценка качества на валидации
   - collate_input_examples(): подготовка батчей

4) Вспомогательные классы:
   - EarlyStoppingCallback: для ранней остановки обучения

--------------------

### 4. Процесс обучения

1) Загрузка и подготовка данных:
   - Загрузка диалогов из Excel
   - Разделение на train/val (80%/20%)
   - Создание пар диалогов для обучения:
     * Положительные пары (одна тема)
     * Отрицательные пары (разные темы)
     * Поддерживается баланс positive/negative примеров

2) Обучение модели:
   - Базовая модель: deepvk/USER-bge-m3
   - Оптимизация косинусного сходства
   - Валидация после каждой эпохи
   - Early stopping при отсутствии улучшений
   - Сохранение лучшей модели

-----------------

### 5. Параметры обучения

- batch_size: размер батча (default: 16)
- epochs: максимальное число эпох (default: 10)
- learning_rate: скорость обучения (default: 2e-5)
- warmup_steps: шаги прогрева (default: 100)
- patience: терпение для early stopping (default: 3)
- val_size: доля валидационной выборки (default: 0.2)

# Модуль оценки схожести диалогов (dialog_similarity.py)

### 1. Назначение

Модуль предназначен для вычисления семантической схожести между диалогами с помощью обученной модели SentenceTransformer. Позволяет сравнивать диалоги, определять, относятся ли они к одной теме, и анализировать качество работы базовой и дообученной моделей.

------------

### 2. Основные классы и функции

1) DialogSimilarity
   - Основной класс для работы с моделью схожести диалогов.
   - Аргументы конструктора:
     * model_name: имя базовой модели (по умолчанию deepvk/USER-bge-m3)
     * model_path: путь к дообученной модели (если None — используется базовая)
     * threshold: порог схожести для определения связанности диалогов

   - Основные методы:
     * is_related(dialogs, query_dialog):
         Проверяет, похож ли query_dialog на хотя бы один из dialogs (True/False)
     * get_similarity_scores(dialogs, query_dialog):
         Возвращает список оценок схожести query_dialog с каждым из dialogs

2) compare_models
   - Функция для сравнения работы базовой и дообученной моделей на тестовых примерах.
   - Выводит таблицу с метриками и подробным сравнением результатов.

-----------------------------

### 3. Особенности реализации

- Диалоги разбиваются на реплики клиента и менеджера, каждой реплике назначается вес (первая реплика клиента — самая важная).
- Схожесть считается с учетом ролей и весов реплик.
- Используется косинусное сходство между эмбеддингами реплик.
- Пороговые значения для определения "похожести" можно настраивать.

--------------------------

### 4. Параметры и настройки

- threshold: основной порог для средней схожести (по умолчанию 0.5-0.6)
- Веса ролей можно изменить в self.weights внутри класса
